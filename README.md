# gcdatlas

A clean-room, from-scratch re-implementation of the idea behind **[eshin087/gcdatlas](https://github.com/eshin087/gcdatlas)** by [@eshin087](https://github.com/eshin087). The original project had no open-source licence, so no code or assets were copied: only the concept (and its public description) was used as inspiration. All code and assets in this repository are original.
